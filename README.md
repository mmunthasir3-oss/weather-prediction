# Weather Forecasting Prediction System

## Project Overview
This project predicts daily average temperature using historical weather data and machine learning techniques.

## Features
- Historical weather data analysis
- Data preprocessing and feature engineering
- Random Forest Regression
- Four-day temperature prediction
- Model evaluation using MAE and R² score

## Technologies
- Python
- Pandas
- NumPy
- Scikit-learn
- Google Colab

## Dataset
Historical weather dataset containing daily weather measurements.

## How to Run
1. Open the Jupyter notebook in Google Colab.
2. Upload the required dataset.
3. Run the cells in order.
4. Enter a date to obtain a four-day temperature prediction.

## Disclaimer
This is an educational machine learning project. Predictions are estimates and are not official weather forecasts.
